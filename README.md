# Lexta platform

Lexta Ghana Limited's websites and business system, built by 1773 Human Resources & Marketing Services LTD.

| App | Folder | Vercel project |
|---|---|---|
| Lexta corporate site | `apps/lexta` | lexta-web |
| Lexta Business System (8 systems, one login) | `apps/portal` | lexta-portal |

Run locally: `pnpm install`, copy `.env.example` to `.env.local` in each app, then `pnpm dev`.
Build rules are in `CLAUDE.md`.
